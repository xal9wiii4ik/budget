# PDF-импорт через LLM + сверка остатков + агент сверки

Скоуп `pdf-reconcile` (портфолио, пункты 3 и 5). Стартует после `ai-layer` (использует его провайдер LLM).

## Как должно работать
- Импорт PDF-выписки Альфа-Банка: текст PDF → LLM извлекает операции по JSON-схеме → сервер проверяет: начальный остаток + операции = конечный остаток из выписки; не сходится — импорт не применяется, показывается разница.
- Сверка остатка после импорта для всех банков: остаток счёта в приложении vs конечный остаток в выписке → «✓ сходится» или «расхождение N».
- Агент сверки: по запросу LLM сравнивает выписку с учётом (инструменты: строки выписки, операции приложения за период) и выдаёт список расхождений с причинами (нет в учёте / лишняя / другая сумма / другая дата / курс).

## Решения владельца
- Альфа, извлечение через LLM. Живой прогон — когда будет ключ или Ollama.
