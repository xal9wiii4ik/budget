# MCP-коннектор для Claude (web / desktop / mobile) через OAuth

Board card: см. доску (project 2), скоуп `mcp-remote`. PLAN: 5.6, фаза 2.

## Зачем
Сейчас MCP подключается только в Claude Desktop через локальный процесс и вставку токена в конфиг — обычному пользователю это тяжело, а с телефона не работает вовсе. Нужно, чтобы любой пользователь Budget подключал свои данные к Claude за минуту, в том числе для использования с телефона.

## Как должно работать
- Пользователь в Claude (claude.ai или Desktop): Settings → Connectors → Add custom connector → вставляет `https://<домен>/mcp`.
- Claude открывает нашу страницу: вход в Budget (если не вошёл) → экран «Claude запрашивает доступ к вашему бюджету» с выбором «только чтение» / «полный доступ» → «Разрешить».
- Дальше в Claude доступны те же инструменты, что у нынешнего MCP (35: 20 read / 15 write) — в чате на сайте, в Desktop и в мобильном приложении (после добавления на сайте).
- В «Настройках» Budget — раздел «Подключённые AI-приложения»: кто подключён, режим, когда последний раз пользовался, кнопка «Отключить» (мгновенно).
- Нынешний способ (Claude Desktop + токен из настроек, `python -m budget_api.mcp`) продолжает работать.
- RU/EN.
