# CI + README

Скоуп `ci-readme` (портфолио, пункт 4).

## Зачем
Тесты есть (~1200), но гоняются только локально; README не объясняет проект человеку со стороны.

## Как должно работать
- GitHub Actions на push/PR в main: API (ruff, pyright, pytest с Postgres-сервисом, alembic check), web/api-client/mobile (lint, typecheck, test через turbo), дрейф контракта openapi.json ↔ schema.d.ts. Кэш зависимостей. Должно укладываться в бесплатные минуты приватного репозитория.
- README: проблема → схема архитектуры → что умеет → как запустить одной командой → тесты/CI → MCP (локально и коннектор) → мультиагентная разработка (роли, уровни ревью, где артефакты) → место под результаты evals.
