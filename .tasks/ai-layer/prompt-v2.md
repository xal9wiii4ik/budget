# categorize-v2: примеры из истории пользователя (few-shot)

Продолжение скоупа ai-layer (PLAN 8.6). Владелец одобрил 2026-10-20.

## Зачем
Живой прогон categorize-v1 (2026-10-20): qwen2.5:7b 39,1%, llama3.1:8b 47,0% при потолке 86,5%. Модель не знает личную таксономию владельца (22 категории: «Напитки» vs «Продукты» vs «Вкусняшки»). Дать ей примеры того, как сам пользователь раскладывал похожие операции.

## Как должно работать
- Промпт `categorize-v2`: к каждой пачке добавляются примеры из истории ЭТОГО пользователя — его уже категоризованные операции (текст → категория). Отбор: самые похожие по смыслу через уже работающие локальные эмбеддинги (RAG-индекс 8.5) + покрытие категорий; лимит по количеству/токенам.
- v1 остаётся доступным (версия промпта — настройка), по умолчанию — та, что лучше по замеру.
- Нет эмбеддингов/истории → v2 честно деградирует до v1-поведения.
- Приватность: примеры — только операции того же пользователя; в логи текст не попадает.

## Как меряем (честно)
- Разбиение набора owner-categorize-v1 на «историю» (пул примеров) и «тест» (детерминированно), без утечки: пример никогда не совпадает с тестовой строкой; отдельно — строки, чей текст уже встречался в истории (их в приложении закрыли бы правила).
- v1 и v2 на ОДНОМ тестовом срезе, обе модели Ollama. Отчёт: точность, unsure, флаги, задержка, токены.
