# Web push reminders

Board card: PVTI_lAHOBDE0X84BhSalzg-5MeM (project 2, xal9wiii4ik).

## Зачем
Напоминания о приближающихся целях, сроках плановых покупок и регулярных платежах сейчас видны только внутри приложения. Нужно, чтобы телефон сам напоминал — без открытия сайта.

## Как должно работать
- В «Настройках» кнопка «Включить уведомления». iOS разрешает запрос только по нажатию, поэтому без автоматических всплывашек. Рядом — «Прислать пробный пуш».
- Раз в день сервер находит пункты целей с `remind_on` / `remind_days_before`, сроки депозитов и ближайшие регулярные платежи и шлёт одно короткое уведомление на каждое устройство пользователя. Без сумм в тексте пуша: он виден на заблокированном экране.
- Тап по уведомлению открывает нужный экран (цель, платёж).
- Можно выключить; подписка «умершего» устройства (ответ 404/410 от push-сервиса) удаляется сама.
- Тексты на RU/EN — по языку пользователя.

## Грумминг (предварительно)
- **Web Push + VAPID.** На iOS работает с 16.4 и только для сайта, установленного на экран «Домой».
- **Web:**
  - обработчики `push` и `notificationclick` в `public/sw.js`;
  - подписка через `PushManager`;
  - секция в настройках.
- **API:**
  - таблица `push_subscriptions` (`user_id`, `endpoint`, ключи, язык), скоуп по `user_id`;
  - эндпоинты subscribe / unsubscribe / test;
  - ежедневный шедулер рядом с существующими;
  - библиотека `pywebpush`;
  - VAPID-ключи в `.env` (добавляет владелец).
- **Контракт:** меняются `openapi.json` и `schema.d.ts`.
- **Нужен HTTPS.**
  - Mac: на `localhost` можно проверять локально (Chrome/Safari), это secure context.
  - iPhone: нужен HTTPS-адрес — Tailscale Serve (бесплатно, без деплоя) или сам деплой.
- **Мобилка (Expo) вне скоупа.** Для неё нужны dev-сборка и APNs-ключ (платный Apple Developer).
