## Ключевые решения (закрыты, см. plan*.md §резолюции)
- Модель S1: amount_minor/currency = списание (математика не трогается), original-пара
  nullable, банковская сумма побеждает серверный курс, base-снапшот от списания.
- Дырка снапшота при серверном выводе суммы — закрыта обязательной правкой + тест с
  мутационной проверкой (PM п.1). Имя курса — `original_rate` (PM п.2). Коды —
  `ORIGINAL_FIELDS_REQUIRED`/`AMOUNT_REQUIRED` (PM п.3).
- `profiles.language` — NULL без default (PM-1); detach/re-attach фото разрешены,
  файл не удаляем, уборка сирот — follow-up только с подтверждением пользователя (PM-2).
- S4 без связки с мобилкой: merchant в PATCH — явным ключом вне buildTransactionPatch.
- Новый роутер /profile (GET+PATCH, JWT-only) — открытие архитектора, вошло в S1.

## Открытые вопросы ПОЛЬЗОВАТЕЛЮ (с рекомендацией)
1. Модель «потрачено/списано» (50 EUR → 165 BYN, курс банка правится) — подтвердить.
   РЕКОМЕНДУЮ: принять, зеркало уже проверенных переводов.
2. Валюта поля траты по умолчанию — РЕКОМЕНДУЮ валюту счёта; валюта страны профиля —
   первым чипом в переключателе (не наоборот: списание всё равно в валюте счёта).
3. Страна+язык при первом входе — РЕКОМЕНДУЮ ненавязчивый баннер с догадкой из локали,
   значение пишется только после подтверждения (до того NULL).
4. «Название» операции = поле merchant с лейблом «Name / place», без третьего
   текстового поля — РЕКОМЕНДУЮ принять (title/merchant/note на одной форме — вредно).
5. Priority целей = селект Высокий/Средний/Низкий (1/2/3), существующее число
   сохраняется опцией «Другой (n)» — РЕКОМЕНДУЮ принять, API не меняется.
6. i18n без библиотеки (лёгкий словарный слой, домены в packages/shared) —
   РЕКОМЕНДУЮ принять; MCP/advisor продолжают видеть русские имена категорий из БД.
7. Мобильная линия (615 мин): заказывать ли и когда; РЕКОМЕНДУЮ первую разморозку
   S4+S2+S1-UI (~230 мин) после веба; фото — только с физическим девайсом.
8. Страна в статистику — РЕКОМЕНДУЮ не сейчас (только CSV), отчёт «поездки» — задел.
9. Follow-up: уборка осиротевших MinIO-объектов — заведён, только по явному
