# QA Web Checklist: recurring-book-now (W1) — «+» = ярлык предзаполненной формы

## Scope
Три живых браузерных сценария по R7 (потолок сжат PM, не расширялся). Проверяется
только то, что навязывает браузер: реальные клики по «+», предзаполнение существующей
формы, отказ формы 422 и восстановление после него, отсутствие подмены счёта,
инвалидация экрана после сохранения.

## Реестр вычеркнутого
- **Материализация по кнопке** (сдвиг ватермарки, идемпотентность двойного клика,
  422 `DUE_DATE_NOT_PENDING`, аррерс, досрочное списание, исчезновение строки виджета)
  — сценарии АННУЛИРОВАНЫ вместе с первой версией скоупа (task.md, R1: бэкенда нет,
  эндпоинта `POST /recurring/{id}/book` не существует). Тестировать нечего: механизма нет.
- **Чистый маппер шаблон→initial values** (экспонента 0/2, `merchant ?? name`,
  `null → ''`) — закрыт vitest `apps/web/src/features/transactions/templatePrefill.test.ts`,
  браузером не переигрывается.
- **`selectableAccounts` держит архивный стартовый счёт** — закрыт vitest
  `apps/web/src/features/accounts/accountOptions.test.ts`; в браузере проверяется только
  наблюдаемый исход (какой счёт выбран в `<select>`), а не сама функция.
- **Контракт POST /transactions, коды и скоупинг** — pytest бэкенда, сервер в этом
  скоупе не менялся.

## Окружение прогона (2026-08-23)
- Docker-контейнеры проекта уже занимали 5173 (собранный образ web) и 8010 (API);
  остановить их не удалось (запрет на действие), поэтому подняты **параллельные**
  экземпляры под незакоммиченный код: API `uvicorn … --port 8011`
  (`CORS_ORIGINS=["http://localhost:5199"]`, `FX_SCHEDULER_ENABLED=false`,
  `RECURRING_SCHEDULER_ENABLED=false`, та же БД на 5443) и vite dev
  `--port 5199 --strictPort` с `VITE_API_URL=http://localhost:8011`.
  Чужие сервисы (5433/8000/8081/5432) не тронуты.
- Указатель в браузерной панели давал несовпадающие координаты (клики не попадали в
  элементы), поэтому сценарии прогнаны Playwright'ом через системный Chrome
  (`channel: 'chrome'`) — те же реальные клики в реальном браузере.
- Пользователь: `qa-booknow-1787491717@budgetqa.dev`. Фикстуры (3 счёта, категория,
  4 шаблона) заведены curl'ом.
