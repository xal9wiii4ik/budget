# mobile-catchup-3 — хвосты после закрытия

- **Счётчик операций без курса — на весь месяц, не на категорию.** Сводка отдаёт
  одну цифру на период; окно/экран категории показывали её как категорийную
  (D-7, оба клиента). Сейчас формулировка честно месячная. Правильная починка —
  серверная: `unconverted_count` в каждой строке `by_category` сводки, это
  правка контракта и четырёх потребителей. Отдельный скоуп, если понадобится.
- **Zod-сообщения shared-схем по-английски** («Enter an amount.») на русском
  интерфейсе — общий пробел веба и мобилки (N-5); `params.reason` никто не мапит.
- **E-1** — чек без распознавания: `view_url` пуст навсегда; серверный скоуп.
- **Фото пунктов плана без `expo-image-manipulator`** — слишком большой файл
  отклоняется словами, а не сжимается; нативный модуль — отдельное решение.
- **Кнопка сброса фильтров** рендерится всегда; веб показывает её только при
  активных фильтрах.
- **Ручной чеклист для физического iPhone** — записан в `qa-mobile-checklist.md`,
  не выполнен (камера, отказ в правах, русский ввод, хаптика, Android-back,
  офлайн, 100+ строк).
