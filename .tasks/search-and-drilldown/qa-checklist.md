# qa-checklist.md — scope search-and-drilldown (15 сценариев, потолок соблюдён)

Полный live-прогон — ОДИН раз в конце скоупа (QA cadence 2026-08-18). Mid-scope
STOP-пробы не нужны: интеграционных границ (внешние API, storage, шедулеры) нет.
Пользователи только `qa-*@budgetqa.dev`. Порты: API 8010, web dev по docs/infra.md.

## API (qa-engineer, pytest уже гейтит — здесь curl-проверки живого поведения)

1. `q=кофе` находит merchant «Кофейня Х» и note с «...кофе...» независимо от
   регистра (создать строки с «КОФЕ»/«Кофе»); латинский `q=coffee` — аналогично.
2. `q=100%` и `q=a_b` ищут ЛИТЕРАЛЬНО (создать merchant «скидка 100%» и «a_b»;
   строка «axb» под `q=a_b` НЕ находится) — экранирование джокеров.
3. `q` под пользователем A не возвращает совпадающие строки пользователя B
   (скоупинг; total тоже честный).
4. `country=PL` возвращает только польские строки; `country=pl` и `country=POL`
   → 422 (паттерн); отсутствие параметра = все строки.
5. `sort=amount_desc` — порядок убывания amount_minor, при равных суммах порядок
   стабилен между страницами (offset-пагинация без дублей/пропусков на границе).
6. `sort=date_asc` — старые первыми; дефолт (без sort) байт-в-байт равен
   сегодняшнему порядку (регресс).
7. Комбинация `q + category_id + from/to + country`: AND-семантика, total
   соответствует items.
8. `GET /transactions/export?q=...&country=...` — CSV содержит только совпавшие
   строки; sort в export не принимается/не влияет (oldest-first).

## Web (web-qa; текст/структура через read_page, скриншоты только для визуала)

9. /categories: у системной И у пользовательской категории есть аффорданс
   «операции»; клик ведёт на /transactions с фильтром этой категории и текущим
   месяцем; чип с именем категории виден; крестик чипа сбрасывает фильтр.
10. Drill-down + MonthPicker: листание месяца сохраняет фильтр категории;
    summary-шапка соответствует месяцу.
11. «За всё время»: включение показывает операции за пределами текущего месяца
    (создать строку прошлым годом), месячная summary-шапка скрыта; возврат к
    месячному режиму работает; URL шареем (открытие по прямой ссылке).
12. /categories поиск: «прод» находит «Продукты» (системная, переведённая) на
    ru-профиле; регистр не важен; пустой результат — заглушка; очистка поля
    возвращает полный список; группы income/expense не перемешаны.
13. /transactions поиск: ввод фильтрует с debounce (сетевой запрос не на каждый
    символ — по read_network_requests), очистка возвращает список; `?q=` в URL.
14. Фильтр страны + сортировка по сумме из popover: список плоский (без
    day-групп) при amount-сортировке, счётчик активных фильтров на кнопке верный,
    сброс фильтров возвращает дефолт.
15. Экспорт с активными q/страна/категория: имя файла и содержимое соответствуют
    отфильтрованному списку; пустой результат — честное сообщение «headers only».
