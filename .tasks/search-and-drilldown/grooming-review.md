## Ключевые решения

1. **Поиск = ILIKE-подстрока по merchant OR note**, без полнотекстового движка.
   PG UTF-8 фолдит кириллицу; джокеры `%`/`_`/`\` экранируются. Индексов НЕ
   добавляем: дефолт месяц-скоупный через (user_id, occurred_at), объёмы
   персональные; pg_trgm — deferred, зафиксировать в docs/backend.md.
2. **sort** — один enum-параметр (date_desc дефолт / date_asc / amount_desc /
   amount_asc), вторичные ключи стабильны. Никакой комбинаторики полей.
   Amount — по amount_minor: все SUPPORTED_CURRENCIES экспоненты 2, сравнение
   честное; конверсии не делаем (base-снапшот нулябелен у transfer/no-rate).
3. **«Расширить диапазон» = переключатель «за всё время»** (from/to опциональны
   на сервере УЖЕ — ноль серверной работы). Кастомный date-range — отложен.
4. **Один механизм фильтра категории**: drill-down (S1) и селект в popover (S3)
   пишут ОДИН URL-параметр `?category=` — второго механизма рядом не появляется.
5. **UI-минимум**: поиск-инпут + компактный popover (категория, страна,
   сортировка). kind-фильтр не делаем — сценарии пользователя его не требуют.
6. **Экспорт-паритет**: q/country — да, sort — нет (D13 oldest-first).
7. **Контракт → 4 потребителя** (политика 2026-08-23): mcp-server allowlist
   получает кураторские описания q/country/sort, тесты всех четырёх пакетов
   в гейте S3.

## Открытые вопросы (рекомендации даны, решаю при имплементации если PM не возразит)

1. Аффорданс drill-down: отдельная иконка-ссылка на строке (рекомендую) vs клик
   по всему ряду (конфликт с edit у пользовательских и с C4-гейтом системных).
2. Плоский список при amount-сортировке (day-группы теряют смысл) — рекомендую
   принять; альтернатива (группы по дням внутри) отвергнута как бессмысленная.
3. Источник опций фильтра страны: полный Intl.DisplayNames-список (рекомендую,
   переиспользование из TransactionFormModal) vs endpoint distinct-стран
   (НЕ делать в v1 — лишний контракт ради удобства, данных мало).
4. Минимальная длина q: серверных ограничений нет, клиент дебаунсит 350мс и
   триммит. Однобуквенный поиск разрешён (рекомендую не усложнять).
