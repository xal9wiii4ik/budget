# Deploy: web + API on one VPS

## Зачем
Сейчас приложение живёт только на маке владельца. Нужно, чтобы 3–10 человек пользовались им с телефона и компьютера по HTTPS, в том числе установив сайт на экран «Домой» и получая пуши (5.2), — без включённого мака.

## Как должно работать
- Сайт открывается по `https://<домен>`; API и чеки — с того же адреса (`/api`, `/storage`), как сейчас в локальном контейнере.
- Наружу открыты только 80/443 (+ SSH по ключу). Postgres, MinIO и API снаружи недоступны.
- Обновление — одна команда на сервере (или с мака): подтянуть код, пересобрать, применить миграции, перезапуститься.
- Каждый день — бэкап базы и чеков; восстановление описано и проверено.
- Секреты живут только в `.env` на сервере.

## Решения владельца
- Хостинг: netcup VPS, x86, 4 GB RAM, Ubuntu 24.04 (Hetzner не прошёл проверку).
- Домен пока не куплен: до покупки — бесплатный `<ip>.sslip.io` с настоящим сертификатом; переезд на свой домен — сменой одной переменной.
- Бэкапы за пределы сервера — Cloudflare R2 (бесплатные 10 GB), когда владелец заведёт аккаунт; до этого — локальная ротация на сервере.
