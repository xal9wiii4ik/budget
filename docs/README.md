# docs/ — ориентационные мини-доки для агентов

Назначение: агент, приступающий к задаче, читает СНАЧАЛА относящиеся мини-доки
отсюда — и только потом точечно код. Это замена массового перечитывания кода.

Правила:
- Одна дока на область: backend.md, web.md, mobile.md, infra.md, conventions.md, mcp.md (packages/mcp-server).
- Потолок ~150 строк на доку: назначение области, ключевые модули/эндпоинты
  (одной строкой каждый), инварианты, точки интеграции, известные грабли.
- НЕ дублировать код и .tasks-артефакты — указывать на них.
- Обновляется senior-lead'ом ПРИ ЗАКРЫТИИ каждого скоупа (до финального отчёта):
  дописать/поправить затронутые области. Устаревшая дока хуже отсутствующей —
  правь при каждом закрытии.
